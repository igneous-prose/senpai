# SENPAI Paper

This directory contains the source and publication artifacts for the SENPAI paper.

- `paper.tex` and `paper.bib`: active camera-ready source.
- `appendix_sources/`: verbatim prompt and programme-contract snapshots included by the appendix.
- `latex/icml2026/`: vendored ICML style and bibliography dependencies required to build the paper.
- `figures/`: final figure assets used by the LaTeX source.
- `figure_sources/`: scripts and reduced source data used to regenerate the figures.
- `build/paper.pdf`: latest PDF built from the active source.
- `icml2026/`: frozen copy of the camera-ready PDF submitted through OpenReview.
- `poster/`: poster PDF and editable PowerPoint source.
- `archive/`: superseded planning and Markdown drafts retained for history.
- `icml/AGENT_FAILURE_MODES1.md`: retained failure-mode notes.

Run LaTeX from this directory so relative figure, appendix, and style paths resolve correctly.
