# Figure Sources

The final publication assets live in `../figures/`. These directories retain the scripts and reduced data needed to regenerate them:

- `cfd_problem_gallery/`: builds `cfd_problem_gallery.pdf` and `.png`.
- `drivaerml_surface_pareto/`: builds `drivaerml_surface_pressure_pareto.pdf` and `.png` from cached W&B and GitHub evidence.
- `willow_sankey/`: builds `willow_simplified_sankey.pdf`, `.png`, and `.svg` from the experiment ledger.

Run the scripts from the repository root. They resolve source data and output paths relative to their own locations.
